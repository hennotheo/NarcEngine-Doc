NarcIO is an I/O library for the NarcEngine game engine. It handles interactions with input devices and file read/write operations.

## Features

- Input device management (keyboard, mouse, game controllers)
- File reading and writing
- Support for various file formats (text, binary, etc.)
- Easy integration with NarcEngine

## Dependencies

- [[GLFW.md]] - For window and input management
- [[STBLIB.md]] - For image processing
- [[TinyObjLoader.md]] - For Obj loading
- [[NarcLog.md]] - Engine Logging Library
